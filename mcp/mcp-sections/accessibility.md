### ♿ <a name="accessibility"></a>Accessibility

- [kinti/a11y-toolkit](https://github.com/kinti/a11y-toolkit) ⭐ 17 [![kinti/a11y-toolkit MCP server](https://glama.ai/mcp/servers/kinti/a11y-toolkit/badges/score.svg)](https://glama.ai/mcp/servers/kinti/a11y-toolkit) 🐍 🏠 - WCAG 2.2 accessibility tools: color contrast checks including text over images, EU accessibility declaration generation and an aria-live announcement monitor.
- [mishan/shotbox](https://github.com/mishan/shotbox) ⭐ 2 [![mishan/shotbox MCP server](https://glama.ai/mcp/servers/mishan/shotbox/badges/score.svg)](https://glama.ai/mcp/servers/mishan/shotbox) 🐍 🏠 🐧 - Runs real GUI programs in a sealed X11 or Wayland session where an agent can read the accessible tree, take screenshots and clips with sound, click, type and drive gamepads, then check what it finds: unnamed controls, contrast, Tab order, screen reader announcements and audio dropouts.
- [kim-dongho/krds-a11y-mcp](https://github.com/kim-dongho/krds-a11y-mcp) ⭐ 1 [![kim-dongho/krds-a11y-mcp MCP server](https://glama.ai/mcp/servers/kim-dongho/krds-a11y-mcp/badges/score.svg)](https://glama.ai/mcp/servers/kim-dongho/krds-a11y-mcp) 📇 🏠 🍎 🐧 - Korea's government design system (KRDS) components with KWCAG 2.2 (Korean web accessibility standard) built in: refuses markup when labels or alt text are missing, checks rendered pages with axe plus real keyboard and contrast measurements, and ships Claude Code/Codex hooks that keep agents from finishing while violations remain.
- [pourdev/pour-cli](https://github.com/pourdev/pour-cli) ⭐ 1 [![pourdev/pour-cli MCP server](https://glama.ai/mcp/servers/pourdev/pour-cli/badges/score.svg)](https://glama.ai/mcp/servers/pourdev/pour-cli) 🎖️ 📇 🏠 🍎 - WCAG 2.2 audits from the pour accessibility engine, written from the W3C specifications: audit a URL or local HTML file for proven failures and items that need a person to review, trace the keyboard focus order, and screenshot a page through vision and motor simulations.
- [vince-gonzalez/opticquiz-mcp](https://github.com/vince-gonzalez/opticquiz-mcp) ⭐ 0 [![vince-gonzalez/opticquiz-mcp MCP server](https://glama.ai/mcp/servers/vince-gonzalez/opticquiz-mcp/badges/score.svg)](https://glama.ai/mcp/servers/vince-gonzalez/opticquiz-mcp) 📇 🏠 🍎 🪟 🐧 - Color-vision accessibility: check palettes and images for colorblind safety, generate safe palettes, simulate color blindness and create Ishihara-style plates.
