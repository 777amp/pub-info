### 🎧 <a name="text-to-speech"></a>Text-to-Speech

Tools for converting text-to-speech and vice-versa

- [mbailey/voice-mcp](https://github.com/mbailey/voice-mcp) ⭐ 1.5k 🐍 🏠 - Voice interaction: speech-to-text, text-to-speech and real-time voice conversations via local microphone, OpenAI-compatible APIs and LiveKit.
- [mberg/kokoro-tts-mcp](https://github.com/mberg/kokoro-tts-mcp) ⭐ 83 🐍 🏠 - Text-to-speech with the open-weight Kokoro TTS models, saving MP3s locally or uploading them to an S3 bucket.
- [loudreader/loudkit](https://github.com/loudreader/loudkit) ⭐ 28 [![loudreader/loudkit MCP server](https://glama.ai/mcp/servers/loudreader/loudkit/badges/score.svg)](https://glama.ai/mcp/servers/loudreader/loudkit) 🐍 🏠 🍎 🪟 🐧 - Local text-to-speech from an on-device model with multiple voices and languages, cloned voice profiles and WAV, FLAC, MP3 or Opus output.
- [ybouhjira/claude-code-tts](https://github.com/ybouhjira/claude-code-tts) ⭐ 21 🏎️ ☁️ 🍎 🪟 🐧 - Text-to-speech for Claude Code using OpenAI's TTS API, with multiple voices and cross-platform playback.
- [daisys-ai/daisys-mcp](https://github.com/daisys-ai/daisys-mcp) ⭐ 14 🐍 🏠 🍎 🪟 🐧 - Generate text-to-speech and text-to-voice audio with the DAISYS platform, and play and store the generated audio.
- [transcribe-app/mcp-transcribe](https://github.com/transcribe-app/mcp-transcribe) ⭐ 8 📇 🏠 - Transcribe audio and video files and voice memos and work with their text content.
- [forgemeshlabs/voice-mcp](https://github.com/forgemeshlabs/voice-mcp) ⭐ 0 [![voice-mcp MCP server](https://glama.ai/mcp/servers/forgemeshlabs/voice-mcp/badges/score.svg)](https://glama.ai/mcp/servers/forgemeshlabs/voice-mcp) 📇 ☁️ - Pay-per-call x402 speech generation on Base: multiple voices, personas and languages, speed and quality controls, OpenAI-style requests and batch audio.
- [fasuizu-br/brainiall-mcp-server](https://github.com/fasuizu-br/brainiall-mcp-server) [![brainiall-mcp-server MCP server](https://glama.ai/mcp/servers/fasuizu-br/brainiall-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/fasuizu-br/brainiall-mcp-server) 🐍 ☁️ - Speech tools: pronunciation assessment with phoneme-level feedback, speech-to-text with language detection and text-to-speech with multiple voices.
